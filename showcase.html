// how to upload your panels to steam [ show ]
01
what you'll need
a steam account with workshop showcase unlocked (usually level 10+ or bought with steam points). this tool handles the slicing — download your panels as a .zip first.
02
resize each panel (optional but recommended)
steam showcase slots display better at a narrower width. go to ezgif.com/resize, upload each panel gif, set width to 184px with aspect ratio locked, then export.
03
optimize file size (if needed)
steam may reject gifs over ~2.5 mb. go to ezgif.com/optimize and apply 20–40% optimization per panel until they're under the limit.
04
hex fix — already done ✓
steam requires the last byte of each gif to be 21 instead of the standard 3B trailer. this tool applies that fix automatically when encoding — panels downloaded from here are already steam-ready. no hex editor needed.
05
upload each panel to steam workshop
go to: steamcommunity.com/workshop/edititem/767/3
right-click → inspect → console tab, paste this and press enter: $J('#ConsumerAppID').val(480),$J('[name=file_type]').val(0),$J('[name=visibility]').val(0); upload one panel gif per submission. paste the code again for each new upload. do this for all panels (4 or 5 items total).
06
arrange panels on your profile
go to: steam profile → edit profile → featured showcase
choose my workshop showcase, then arrange:
panel 1→ leftmost slot panel 2→ second slot panel 3→ middle slot panel 4→ fourth slot panel 5→ rightmost slot (if 5-panel)
save and preview your profile — the panels should form one continuous gif.
